## Adding a CRUD slice

1. Add a Prisma model and a migration. Choose stable identifiers and an index that supports the first list query.
2. Add a Nest module with request and response DTOs, authorization checks and bounded pagination. Start with one create-and-read test using PostgreSQL.
3. Run `pnpm contract:generate`, then use the generated route from `@forge/api-client` in the Next page.
4. Add Persian field labels, form errors, loading, empty and error states. Add tests that exercise the same-origin route and both permitted and forbidden access.

## Adding a permission or a background job

Extend the account guards and add a scoped permission such as `workspaces:manage`, grant it to the appropriate role in config, and require it on mutations. Test wrong-role and logged-out requests on the API.

When a feature requires a durable queue, add Redis and BullMQ as an opt-in module in that feature. For a job such as `booking.reminder`, decide the stable job identity and how the handler detects a completed delivery before enabling retries. Keep worker infrastructure optional and document queue failure behavior.
